# RecallLoom v0.4.6.2

RecallLoom v0.4.6.2 is an emergency P0 bugfix on the v0.4.6 line. It keeps the
sidecar protocol at `1.0` and is recommended for users on v0.4.6.1 or older.

## Fixes

- Write-readiness now depends on a shared strict sidecar integrity gate before
  mutating helper actions can proceed.
- `preflight`, `status`, `resume`, `quick-summary`, and `record --plan` now
  align their safe-write signals when strict validation detects unsafe sidecar
  state.
- The dispatcher no longer issues append, write, or current-state sync bindings
  when the strict gate fails.
- Direct append and current-state write helpers recheck strict integrity inside
  the write path before mutating managed files.
- Post-append current-state sync can no longer use the metadata-refresh lane
  when the underlying sidecar integrity gate is not satisfied.
- Recovery review and promotion helpers now require the same strict safety
  boundary before recording reviewed baseline state or exposing promotion write
  context.
- Strict-failure responses now point users toward review/repair instead of
  showing an unsafe retry command.

## Compatibility

- Package version: `0.4.6.2`
- Sidecar protocol: `1.0`
- Python: `3.10+`
- Existing protocol `1.0` workspaces do not need sidecar migration.
- The existing public `v0.4.6` and `v0.4.6.1` tags are not moved; this release
  uses a new immutable v0.4.6-line version.

## Upgrade

Users on v0.4.6.1 or older should update.

Skills CLI:

```bash
npx skills update
```

Directory install:

Replace the installed `recallloom/` skill directory with this release package.

Native wrappers:

Rerun `install_native_commands.py` after updating if native commands are
installed.
