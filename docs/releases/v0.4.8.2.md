# RecallLoom v0.4.8.2

RecallLoom v0.4.8.2 is a narrow compatibility hotfix for ordinary pre-D5
reviewed baselines created by the supported recovery-review path.

## Fixed

- Full provenance validation could incorrectly treat an ordinary
  `review_imported_baseline` as current receipt-backed evidence and report a
  receipt/state mismatch.
- Validation now verifies the exact stored proposal and review material against
  the metadata produced by the supported promotion path, including its legacy
  terminal-newline normalization, before recognizing that baseline as reviewed
  but non-receipt-backed.

## Safety And Compatibility

- Missing, changed, malformed, ambiguous, or mismatched review material remains
  blocked.
- D5 binding validation and receipt-backed validation are unchanged.
- The first mutating write from a reviewed baseline still requires
  `--confirm-review-imported-baseline` and must finalize its own receipt before
  claiming `helper_evidenced`.
- Package version: `0.4.8.2`
- Sidecar protocol: `1.0`
- Python: `3.10+`
- Existing workspaces do not need sidecar migration or historical receipt
  rewriting.

## Upgrade

Upgrade is recommended for users whose workspace contains an ordinary pre-D5
reviewed baseline. Other protocol `1.0` workspaces remain compatible, and this
patch does not raise the minimum mutating or read-only package version.

Skills CLI:

```bash
npx skills update
```

Directory install:

Replace the installed `recallloom/` skill directory with this release package.

Native wrappers:

Rerun `install_native_commands.py` after updating if native commands are
installed.

## Validation Summary

Validation covered the ordinary reviewed-baseline transition, changed review
material, supported large materials, the legacy terminal-newline digest, the
existing D5 path, affected provenance regressions, and an exact copy of the
mother workspace before and after its first confirmed write.
Validation assets and private release evidence are not included in the public
package.
