# RecallLoom v0.5.0

RecallLoom v0.5.0 is a stable write-path architecture release. It consolidates
the previously distributed write flow into explicit final owners while preserving
the protocol 1.0 sidecar contract and existing workspace compatibility.

## Changed

- Managed write, daily-log append, and post-append summary sync now use one
  transaction orchestration boundary with explicit preview/apply, cut-point,
  post-write verification, provenance, and final-evidence handling.
- Input acquisition is consolidated behind a host-neutral transport contract for
  existing input modes plus bounded ASCII capsules and prepared-input handling.
- Atomic replacement and workspace token locking have explicit bounded retry,
  exact-byte identity checks, post-replace readback, and guarded lock lifecycle
  ownership.
- Receipt finalization reuses a single validated store snapshot while retaining
  raw CAS and exact readback safeguards.
- `append`, `write`, and `sync-current-state-after-append` support compact typed
  transaction output without changing the legacy human or JSON 1.1 contracts.
- Same-day support caching is constrained to a current, contract-valid advisory
  and continues to fail closed for stale, invalid, offline, or explicit-local
  advisory conditions.

## Safety and compatibility

- Package version: `0.5.0`
- Sidecar protocol: `1.0`
- Python: `3.10+`
- Existing protocol 1.0 workspaces do not need sidecar migration or historical
  receipt rewriting.
- The final owners retain strict input, revision, marker, privacy, lock, receipt,
  and post-write verification gates; unsafe or unknown write outcomes remain
  inspect-first rather than automatically replayed.

## Windows validation

Private validation on Windows 11 passed in both PowerShell 7.6.4 and Windows
PowerShell 5.1. It covered UTF-8 Chinese/emoji CRLF long trailing-newline input,
real open-handle atomic replacement collision and bounded retry, `msvcrt` lock
mutual exclusion/release, and the capsule boundary. Validation assets and raw
evidence are not included in the public package.

## Upgrade

Upgrade is recommended for all users. This release does not raise the minimum
mutating or read-only package version.

Skills CLI:

```bash
npx skills update
```

Directory install:

Replace the installed `recallloom/` skill directory with this release package.

Native wrappers:

Rerun `install_native_commands.py` after updating if native commands are
installed.
