# RecallLoom v0.4.7

RecallLoom v0.4.7 is a recommended stable workflow and usability update. It
keeps the sidecar protocol at `1.0`, requires Python `3.10+`, and does not
require sidecar migration for existing protocol `1.0` workspaces.

## Highlights

- Ordinary `record --plan` output now centers on one user-visible conclusion,
  one reason, and one next step while detailed bindings remain available in
  structured output.
- New side-effect-free `record --suggest` can identify a durable milestone and
  offer a sanitized recording candidate without writing project memory.
- Post-recording closeout now distinguishes expected append-only freshness from
  semantic change, reducing unnecessary stale-state alarm after a successful
  record.
- `quick-summary`, `status`, `preflight`, `record`, and `validate` use a more
  consistent user-visible status and next-step vocabulary.
- Confirmation material is generated from one shared contract and still
  requires a separate user or operator decision.
- Daily-log cursor repair now uses preview identity, expected revision, and
  explicit apply binding; successful repair remains review-required until a
  post-repair preview or validation is complete.
- Recording privacy handling is shared across suggestion and plan paths for
  POSIX absolute paths, Windows drive paths, and UNC paths.

## Safety And Compatibility

- The strict sidecar-integrity write gates introduced in v0.4.6.2 remain in
  place for append, write, sync, and recovery follow-up paths.
- `record --plan` and `record --suggest` are read-only and side-effect-free.
- Unsafe recording input does not expose a mutating command or echo raw local
  paths through ordinary, full, or compact output.
- Repair apply does not imply that a later write is ready.
- Package version: `0.4.7`
- Sidecar protocol: `1.0`
- Python: `3.10+`
- Existing protocol `1.0` workspaces do not need sidecar migration.

## Upgrade

Upgrading to v0.4.7 is recommended for all users. v0.4.6.2 remains protocol
compatible; this release does not raise the minimum mutating or read-only
package version.

Skills CLI:

```bash
npx skills update
```

Directory install:

Replace the installed `recallloom/` skill directory with this release package.

Native wrappers:

Rerun `install_native_commands.py` after updating if native commands are
installed.

## Validation Summary

Validation for v0.4.7 covered:

- package compilation and documented workflow smoke checks
- initialization, recording-plan, recording-suggestion, and cursor-repair flows
- portable path privacy across POSIX, Windows drive, and UNC forms
- repair preview/apply binding and post-repair category invariants
- clean installable package contents without project memory, caches, logs, or
  maintainer-only files
- a cold-start performance check with no gross regression against v0.4.6.2
