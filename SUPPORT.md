# Support / 支持

This page explains where to ask for help with RecallLoom.

这页说明如何获得 RecallLoom 相关帮助。

## Start Here / 先看这里

- Install and daily use / 安装和日常使用: [README.md](./README.md)
- Command details / 命令细节: [USAGE.md](./USAGE.md)
- Installed skill behavior / 安装后的技能行为: [skills/recallloom/SKILL.md](./skills/recallloom/SKILL.md)
- Release notes / 版本说明: [docs/releases/](./docs/releases/)

## Open an Issue For / 适合开 issue 的情况

- installation problems
- 安装问题
- reproducible helper errors
- 可复现的 helper 错误
- unclear documentation
- 文档不清楚
- compatibility problems with supported host tools
- 与支持的宿主工具有关的兼容问题
- feature requests tied to a specific workflow
- 和具体工作流相关的功能建议

Please use the issue templates and include redacted output when relevant.

请使用 issue 模板，并在相关时提供已脱敏输出。

## Do Not Open a Public Issue For / 不适合公开 issue 的情况

- secrets, tokens, sensitive paths, or personal project memory
- 密钥、token、敏感路径或个人项目记忆
- customer or workspace data
- 客户数据或工作区数据
- security vulnerabilities
- 安全漏洞
- broad consulting requests unrelated to RecallLoom behavior
- 与 RecallLoom 行为无关的宽泛咨询

Security issues should follow [SECURITY.md](./SECURITY.md).

安全问题请遵循 [SECURITY.md](./SECURITY.md)。

## What To Include / 需要包含什么

For useful support, include:

为了更快定位问题，请包含：

- RecallLoom version
- RecallLoom 版本
- install method
- 安装方式
- host tool, if relevant
- 相关宿主工具（如果有）
- operating system
- 操作系统
- Python version
- Python 版本
- the command or prompt you used
- 使用的命令或提示语
- expected behavior
- 预期行为
- actual behavior
- 实际行为
- redacted output
- 已脱敏输出

Small, reproducible examples are much easier to diagnose than screenshots or
large logs.

小而可复现的示例通常比截图或大型日志更容易诊断。
